# Portfólio Gabriela Lopes

Versão estática do portfólio de Gabriela Lopes, analista de marketing, designer gráfica e produtora publicitária. Publicada temporariamente pelo GitHub Pages.

- `index.html`: a página, com o estilo e o JavaScript dentro do próprio arquivo.
- `data/portfolio.json`: todo o conteúdo do site (perfil, experiência, formação, habilidades, contatos e projetos).
- `uploads/`: imagens e vídeos dos projetos.

Para mudar um texto, edite `data/portfolio.json`. Para testar no computador, rode `python3 -m http.server` nesta pasta e abra `http://localhost:8000`.

A versão completa, com painel administrativo, API em Node.js e banco PostgreSQL, roda com Docker numa VM própria.
